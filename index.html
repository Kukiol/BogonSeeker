BOGON / REU
REPRESENTACIÓN ESPACIAL UNIFICADA

Una geometría puede ser una función.

En REU, la forma no se guarda como una lista de triángulos. Una trayectoria paramétrica genera las muestras que necesitamos.

GEOMETRÍA CLÁSICAvértices → aristas → caras → malla
BOGON / REUfunción → evaluación → muestras → detalle adaptativo

El nivel de detalle puede concentrarse donde el observador lo necesita. No confundimos las muestras con vértices: son puntos evaluados sobre una representación continua.
